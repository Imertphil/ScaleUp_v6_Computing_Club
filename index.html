03 · Alphabet Soup

We intercepted this message. Letters, numbers, and an equals sign at the end... that ending is a big clue.

RUNDe2I0c2U2NF8xc19uMHRfM25jcnlwdDEwbn0=
Hint

04 · Caesar's Salad

Julius Caesar shifted every letter to hide his messages. This one is shifted too. Notice how RPP sits where ECC should be.

RPP{e0g13_e0haq_4aq_e0haq}
Hint
R→E is a shift of 13. Try the ROT13 operation in CyberChef. Numbers and symbols don't move.

05 · Locked Button

Only club officers are allowed to claim the coin, so the button is disabled for you. Is it, though?

Hint
Right-click the button → Inspect. In the Elements panel, find the word disabled on the button tag, double-click it, delete it, press Enter. Now click the button.

06 · Admin Login

The admin panel checks your password. The check happens right here in your browser, which means the answer has to be somewhere in the page code...

Hint
Inspect the page and scroll to the <script> near the bottom of the Elements panel. Find the function called checkPassword. The password is stored backwards.
